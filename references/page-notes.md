# 逐页详解与模拟追问

## 交付原则

逐页详解与 PPT 同批生成，页码和标题必须与最终 PPT 一致。它服务的是“汇报者如何讲、如何答”，不是把页面上的文字再抄一遍。

## 每页模板

```markdown
## 第 N 页｜问句标题

- **核心结论**：本页标题下显示的一句答案。
- **建议用时**：MM:SS；全页累计时间不超过汇报净时长。
- **开场接句**：如何承接上一页，不使用“接下来我们来看”。
- **讲述顺序**：按 2–4 个动作说明先指哪里、再解释什么、最后收束到哪。
- **为什么这样讲**：说明本页在整条证据链中的必要性。
- **视觉锚点**：原图/表/示意图的准确位置。
- **视觉引导**：需要指向或高亮的区间、极值、对照组或机制路径。
- **证据**：相关证据 ID 与 PDF 页码/表图编号。
- **页底承接**：本页结论如何产生下一页问题；最后一页写收口句。
```

## 模拟追问

每页至少准备 1 个高概率追问；关键方法页和结论页准备 2–3 个。按以下类别覆盖，而不是只问名词定义：

| 类别 | 典型问题 |
|---|---|
| 设计必要性 | 为什么必须这样分组、建模或选基线？ |
| 替代方案 | 为什么不用更简单、更便宜或更常见的方法？ |
| 数据可信度 | 重复数、误差、异常值和对照是否足够？ |
| 因果与机制 | 现有证据能否排除另一种解释？ |
| 边界与外推 | 换材料、数据集、工况或尺度后还成立吗？ |
| 工程落地 | 计算成本、部署条件和失败代价是什么？ |

每个答案使用三段式：

1. **先答一句**：直接回应，不绕背景。
2. **再给依据**：引用证据 ID 或明确写“本次推断”。
3. **最后补边界**：说明什么情况下答案会改变。

## 不得编造答案

- 原文有答案：给出来源位置。
- 原文没有但可合理推断：写“基于……可以推断”，并列出推断链。
- 需要额外实验、计算或资料才能回答：写“目前不能确定”，给出最小补证方案。
- 不为显得准备充分而编造误差、参数、实验次数或作者意图。

## 全篇彩排检查

- 总用时是否留出演示、换页和临场停顿余量。
- 是否至少有一个针对核心结论的质疑和一个针对边界的追问。
- 是否存在只能回答“作者就是这么做的”、无法解释理由的页面。
- 删掉任一页后证据链是否断裂；若不断裂，考虑合并该页。
