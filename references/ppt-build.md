# 页面制作：把提纲变成能看的页

## 一、先定"块"，再排"页"

不要一页一页想版式，先定义 6–8 个可复用的块，页面只用块来拼：

| 块 | 用途 | 典型位置 |
|---|---|---|
| `stats` | 左列大数字 + 单位 + 一句解释 | 场景页、参数页 |
| `steps` | 编号 + 标题 + 说明 +（可选）注 | 背景、流程、边界 |
| `cards` | 左侧竖线的卡片，含"做法/代价" | 关键动作、可搬的经验 |
| `kv` | 左窄标签 + 右长说明 | 工艺参数、边界清单 |
| `table` | 表头深色、隔行浅底 | 参数表、误差表 |
| `note` | 浅底横条，左竖线 | 关键判断、易错提醒 |
| `quote` | 一句话放大 | 转折点、结论句 |
| `chart` | 柱/条/折线 | 只在有真实数据时用 |

好处：23 页里 90% 的版式问题在块这一层就解决了，页只是 `left + right + 承接句` 的组合。

## 二、固定骨架（1280×720）

```
标题（问句，24pt，宽 1010）        页码标识（10.5pt 灰）
────────────────  62×2 短横线
[ 左栏 w=420–470 ]   [ 右栏 flex=1 ]   gap 26
[ 承接句横条：浅底 + 左侧 3px 竖线 + "下一页" 字样 ]
页脚：来源 | NN / total（绝对定位到底部 13px）
```

- 标题必须留两行空间：问句写到 24–26 字就够，超过会压到内容
- 左栏放"数"，右栏放"理"——数字列左、解释列右，视线从左到右完成"看到 → 理解"
- 承接句横条高度约 34–40px，`marginTop: 10`，不要贴到底部页脚

## 三、图怎么画（只用真实数据）

**能画图的三种情况**：

1. **矩阵**：用嵌套 `Box` 画格子，每格写"≥2 件"。比一句"4×4 矩阵"直观得多。
2. **对比数值**（如过渡寿命 Nt 随温度变化）：用 `Chart` 的 `barChart`，数值必须是文中实际给的值。
3. **从里到外的层级**（断口的三层、损伤的三个层次）：用编号 `steps` 竖排，靠缩进和字号区分层级。

**不能画的情况**：只有趋势描述、没有具体数字的曲线。为了好看编一条"示意曲线"，等于伪造数据——评审一眼能看出来，代价极高。

`Chart` 要点：
```jsx
<Chart style={{ height: 250 }} chartType='barChart' barDirection='bar'
  showLegend={false} showDataLabels={true}
  colors={['#1E4FA8', '#1E4FA8', '#1E4FA8', '#A5473F']}
  data={[['温度','Nt'], ['25 ℃', 24845], ['250 ℃', 48555]]} />
```
- 数值必须是 `number`，字符串会渲染失败
- `barDirection` 只能是 `'bar'` 或 `'column'`，写 `'horizontal'` 无效
- 同一系列里想突出某一根柱子，就在 `colors` 里逐项给色

## 四、文本排版

- 正文 10.5–11.5pt，行高 1.45–1.55；低于 10pt 在投影上看不清
- 层级只靠**字号 + 颜色**：标题 24 / 小标题 12.5 / 正文 11 / 注释 10
- 强调用加粗 + 深色，不要用高亮底色（投到投影上会糊成一片）
- 中文引号用「」或""，代码里的属性值用 ASCII 直引号
- **不要在文本里写 `<` 或 `>`**：会被当成标签起始，导致整页写不进去。要写"小于/超过"

## 五、常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 页面写入失败、无报错细节 | 文本里含 `<` `>` | 改成"超过""以内" |
| 内容溢出到页脚 | 左栏块太多或字号偏大 | 减一个块，或把 `note` 换成一行 |
| 图表空白 | `data` 里数值是字符串，或没给 `height` | 数值转 number，补 `style.height` |
| 表格挤压 | 行数超过 7 行 | 拆成两栏，或只留关键行 |
| 标题换行压住内容 | 问句太长 | 压到 26 字内，或把修饰语挪进正文 |

## 六、逐页闭环

每页：写源文件 → 写入文稿 → 检查版式 → 通过再下一页。**不要攒到最后一起检查**——一处失败会污染后续页序，回滚成本高。

全部完成后核对两件事：
1. 页数与提纲一致（少页通常意味着某次写入被跳过）
2. 每页标题读一遍，连起来像不像一段对话
