# 版式规范：章节式汇报版（deck-style）

一种“按论文结构走”的版式：章节标签固定在左上，每页用一条满宽结论句承担“结论先行”，主体是 2–3 栏卡片。

适用于：组会文献汇报、论文精读分享、中期/结题汇报这类“一篇论文讲 6–12 页，按内容需要可继续加页”的场景。
不适用于：需要强视觉冲击的路演型 deck。

**页数不设上限。** 一页只回答一个问题；问题多了就加页，不要为了卡页数把两问压进一页，也不要为了省页删掉证据或把图缩成缩略图。参考分布：15 分钟 6–8 页、30 分钟 10–14 页、45 分钟 15–20 页——只是参考，不是指标。

**多篇材料各做一套。** 两篇论文可以共用同一套母版与页型，但各自独立叙事：不要求在篇间建立因果链，也不写“与本人研究方向的关系/借鉴”，除非用户明确要求。目标是“这篇讲清楚了”，不是“这两篇凑成一条线”。

---

## 一、标题策略（三选一，默认 C）

| 方案 | 页面顶部写法 | 何时用 |
|---|---|---|
| A 章节式 | 只放「实验设计」「实验结论（1）」 | 听众只关心结构，汇报节奏快 |
| B 问句式 | 只放「多少度开始掉寿命？」 | 听众需要被问题牵引，教学型 |
| **C 双层（默认）** | 章节标签 + 其下一行小字问句 | 两者都要：既交代结构，又保留牵引 |

C 方案的写法：章节标签 26px 深蓝，紧下方一行 17px 中灰问句；两者合计高 ≤ 74px，不得挤压结论条。

无论选哪种，**结论条必须存在**，它是“结论先行”的唯一载体，不能用标题替代。

## 二、版面栅格（1280×720，坐标左上原点）

| 元件 | 区域 | 字号 / 颜色 |
|---|---|---|
| 章节标签 | x 40–640，y 14–50 | 26px，`#1E4FA8`，加粗 |
| 页内问句（方案 C） | x 40–900，y 52–74 | 17px，`#8B97A8` |
| 核心结论条 | x 65–1220，y 105–143（底色 100–148） | 21px，`#1A2230`，底 `#E8EFF8`，左侧 5px `#1E4FA8` 竖条 |
| 主体区 | x 40–1240，y 185–560 | 卡片标题 21px / 正文 17–18px |
| 红线句（可选，每页 ≤1） | 卡片内底部 | 16px，`#D9534F` |
| 底部备注条 | x 58–1222，y 586–652 | 16px，`#4A5568`，浅灰底或细边框 |
| 页码 | 右对齐 `x ≤ 1240`，y 688–704 | 13px，`#8B97A8`，格式 `当前 / 总页数` |

**硬约束**

1. **结论句默认不套满宽色条**：常规页用「22px 章节名 + 19px 结论句」（无底色），靠字号和位置承担“结论先行”。满宽浅蓝结论条（`#E8EFF8` + 左竖条）只留给**全篇核心判断那一页**或**反直觉结果页**，一篇 ≤2 条。页数多了以后逐页套色条 = 每页都在喊，等于没有强调。
2. **承接句写进讲述提纲，不占 PPT 页脚**：每拍一行「承接：把本页结论转成下一页要回答的问题」，≤40 字，供讲述时用。PPT 底带只放术语、图注、页码，保持页面干净。用户明确要求“页面上要看得见承接”时，才在页码左侧加 13px 灰字。
3. 主体区栏数 ≤ 3；三栏时用 Ⅰ / Ⅱ / Ⅲ，两栏时不用编号。
4. 卡片高度必须齐平，误差 ≤ 8px；内容撑不满就换页型，不要留大空白。
5. 页码格式 `当前 / 总页数`，分母写**该篇实际页数**，由生成时按页数自动填，不要沿用模板旧值。
6. 每页只允许一个红色元素（红线句或一个高亮数字），红色是稀缺资源。
7. **一页一问**：页内问句只能有一个问号。若标题里出现两个问题（如「改了什么、改了多深」），拆页或砍掉一个。
8. **边界与迁移是可选页（P6）**：用户要“只讲论文本身”时删掉；要“讲这对我的课题有什么用”时独立成页，不许压成三栏里的一栏。两种都合法，但要在提纲阶段就问清楚，不要默认加上。

## 三、四种基础页型

| 页型 | 结构 | 典型用途 |
|---|---|---|
| P1 封面 | 中文大标题 + 英文出处 + 一行身份（汇报类型/时长） | 每篇第 1 页 |
| P2 三栏 | 结论条 + 三张等宽卡（编号 + 标题 + 正文 + 红线句） | 实验要求、三条并列结论 |
| P3 两栏 | 结论条 + 左右两卡（各含小标题与 2–3 段） | 现象 vs 机制、方法 vs 结果 |
| P4 结果表 | 结论条 + 表头行 + 数据行 + 一行读法 | 误差表、性能对照 |
| P6 边界与迁移（可选） | 结论条 + 三栏「可搬 / 重标 / 未报告」+ 一条推断 | 用户要“对我课题有什么用”时 |

需要“流程/链路”时用 P5：结论条 + 横向 3–5 个步骤卡 + 底部一句代价说明。

### P3 / P4 的差异只在中段

- P3：把 `flexDirection: 'row'` 的两个 `flex: 1` 卡片保持；每卡内可分“小标题 + 2 段 + 底句”。
- P4：中段改为“表头行 + N 个数据行”，行高 30–34px，交替不加底色；表格最后加一行 `#FFF8F1` 底色的“读法”条。

## 四、术语首现即注解

第 1 次出现的专业缩写，在**当页底部备注条**里给全称，不放进正文（正文要塞论证）。

写法：`EBSD（电子背散射衍射）看 KAM（核平均取向差）、SEM（扫描电子显微镜）看断口、TEM（透射电子显微镜）看位错组态。`

规则：

1. 只在首现那页注解，后续页面不再重复。
2. 术语表统一放底部备注条，一条 ≤ 90 字；超了拆到下一页的备注条。
3. 中文全称在前、缩写紧跟，不要写成“KAM（Kernel Average Misorientation）”这种纯英文展开——听众是中文学术环境。

## 五、从提纲到页面

提纲的每一拍落成一个页面，映射关系固定：

| 提纲字段 | 页面元件 |
|---|---|
| `title`（问句或板块名） | 章节标签 / 页内问句 |
| `detail`（核心结论 + 证据） | 核心结论条（证据编号移到备注条） |
| `note` 的视觉锚点部分 | 主体区版式选择（决定 P2/P3/P4） |
| `note` 的承接句 | 不进页面，写进讲述提纲 |
| 该拍涉及的术语 | 底部备注条 |

**页型要在提纲阶段就定好**，写在提纲每拍的备注里（如 `页型 P3`）。到了制作阶段只做填格，不再重新设计版面——这是保证多篇汇报版式统一的关键。

## 六、交付前自检（逐页过一遍）

1. 页内问句是否只有一个问号？（两个问题就拆页——页数不设上限，别硬压）
2. 满宽浅蓝结论条是否 ≤2 条？其余页是否用「章节名 + 19px 结论句」？
3. 提纲里每拍是否有承接句？最后一拍是否为收口句？
4. 页码分母是否等于实际页数？
5. 每页红色元素是否 ≤1 处？表格里是否只用了短下划线、没有长框？
6. 卡片是否齐平（误差 ≤8px）？有无内容撑不满的空白卡？
7. 术语首现是否在当页底带给中文全称？后续页是否重复注解？
8. 若做了「边界与迁移」页，是否写清「可搬 / 重标 / 原文未报告」？若没做，是否是用户明确说不要？
9. 底带的口径说明（如「2018 MPa 为整体平均」）是否完整，能否支撑答问？
10. 图是否大到能读懂？有没有被缩成缩略图的图？

十条全过再交付。任何一条不过，先改页面，不要靠口头解释补救。

## 七、母版带与配图（学术汇报的底线）

学术汇报的观感来自“统一”和“有图”，不来自装饰。以下五条为硬约束。

### 1. 固定母版带，内容不得侵入

把页面切成三条水平带，全篇不变：

| 带 | 范围 | 内容 |
|---|---|---|
| 顶带 | y 0–56 | 左侧 13px 灰字「章节名」；右侧 13px 灰字页码；下沿 0.5px `#D6DCE5` 细分隔线 |
| 内容带 | y 64–640 | 只放结论句、图、要点。**不得有任何母版元素** |
| 底带 | y 656–720 | 左侧 11–12px 灰字来源/口径（如「数据：原文 Table 3」）；上沿细分隔线 |

要点：**母版是“底页”，内容是“浮在上面的卡片”**，两者不掺和。不要每页重新画标题条或装饰线，也不要让图压到顶带或底带上。

### 2. 图是增强项，按内容加，不按页数摊

有能画的东西就画（数据表、结构、流程、对比），没有就纯文字排版，**不必每页配图**。判断标准：**遮住文字，图能不能独立说明一件事？** 不能就是装饰图，删掉。

**图放不下就加页**：一张图被缩成缩略图，等于没画。宁可单开一页把图和结论给足，也不要把三张图挤进一页。

可用的四类图（按可信度排序）：

1. **数据图**：有原文表格数值时画柱/折线，底带注明「数据：原文 Table 3」，不写“示意图”。
2. **示意曲线**：没有原始数值但趋势明确时画，**必须标注「示意图，非实测」**。
3. **结构/机制示意图**：断口同心结构、位错演化、工艺路线，标注「示意图」。
4. **流程链**：3–5 个步骤卡 + 箭头。

**禁止**：把文字要点拆成“图标 + 短句”的营销式排版；禁止无数据支撑的精确曲线。

### 3. 重点要标出来，且只标 1–2 处

一页只允许一个“视觉重心”，手段按优先级：

1. 红色 2px 细框（`#D9534F`）圈住关键数字或关键区域；
2. 箭头/引线指到具体位置 + 12px 红字说明；
3. 浅黄底高亮（`#FFF8E1`）标关键行。

不许整段加粗，不许整页飘红。**读完后听众记住的应该是那一个框。**

### 4. 克制：不用装饰性元素

学术汇报不需要渐变、阴影、圆角大卡片、彩色图标、色块分区。全篇颜色控制在：深蓝（主）+ 灰（字）+ 红（重点）+ 浅灰底（表格头/高亮）。

### 5. 图注规范

图下方 12px 灰字，格式：`图 N　说明（数据来源/是否示意）`。图内坐标轴必须有量和单位；没有单位的概念图不用坐标轴，改用引线标注。

### 6. 三页统一：直接在数据/结构上标注，而不是另画抽象图

有原文数值时，**优先把数据排成表，用细红框直接圈住关键单元格**，不要先抽象成柱状图再回头解释——柱图把数值藏起来，读者要在“柱高→数值→结论”之间转两次。

同一份 deck 里三种页面的标注方式必须一致：

| 页型 | 呈现 | 重点标注 |
|---|---|---|
| 数据页 | 表头浅灰 + 数据行，数值直接给 | **红字加粗 + 2px 红色短下划线**（只压住数字本身，不套长框），字号放大 2–4px |
| 结构页 | 同心结构/流程/示意 | 红色细框或红色左边条 + 红色图例文字 |
| 结论页 | 三栏文字 | 红色 2px 框套住结论段 |

三条共同纪律：**标注只压住要强调的那几个字**（数字短、句子长才用框）、**不填充**、**全篇同一处逻辑**（框住“你要记住的那个数/那句话”）。一页只标一处；标多了等于没标。

**表格里不要用长框**：单元格有固定宽度，框会撑满整列，看起来像加了边框线而不是强调。数字用短下划线，长句才用框。

## 八、机构母版（可选，默认太原科技大学）

有固定单位时直接用这一套，不要每份 deck 重新设计；**换单位或对外交付时按本节末尾三条改**。

| 校徽文件 | `assets/tyust-logo.png`（白色版，420×86，透明底；Skill 的 `assets/` 下已存一份，**每份 deck 需复制到该项目自己的 `assets/`**） |
| 校名 | 太原科技大学 / TAIYUAN UNIVERSITY OF SCIENCE AND TECHNOLOGY |

**母版带（全篇固定）**

| 带 | 范围 | 内容 |
|---|---|---|
| 顶带 | y 0–56，深蓝 `#0024B3` | 左：校徽 `width 118 / height 24`（左距 40）；右：页码 12px `#BFD0F5`，格式 `当前 / 总页数` |

内容带里不放任何母版元素（色条、装饰线、页脚文字）。母版是“底页”，内容是“浮在上面的卡片”。

**封面**

顶部 232px 深蓝块，左放校徽 `300×61`，右侧 15px `#BFD0F5` 栏目名；下部白底放标题（42px，最多两行）、副标题问句（19px）、3px 深蓝短横、出处与场景。封面不放数据、不放页脚。

**纪律**

- 校徽只按比例缩放，**不许改色、加投影、加底板、裁掉文字部分**。
- 不要每页放校训；校训只在封面或结束页用一次（可选）。
- 深蓝底一律配白字或 `#BFD0F5`，不得配深灰。

**换成其他机构 / 不带校徽**

| 场景 | 改法 |
|---|---|
| 换单位 | 替换 `assets/tyust-logo.png`（白色透明版，封面用宽度 ≥300px、顶带用 118×24）；把本节色值改成对方标准色；坐标不动 |
| 不带机构 | 顶带左侧 `Image` 换成「汇报人 · 日期」12px `#BFD0F5`；封面顶块只留标题 |
| 对外分发 | `examples/` 的样张含真实论文数据（*Materials* 2020, CC BY），交付第三方前换成中性示例或删除该目录 |

默认行为：**不主动加机构元素**——只有用户提供了单位或明确要求时才套这一节。
